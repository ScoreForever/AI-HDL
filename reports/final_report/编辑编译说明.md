# 编辑与编译

本目录为正式报告文体的独立版本，旧版报告保留在原目录。

## 修改正文

直接修改 report.tex，运行 `bash build.sh`；也可在当前目录执行两次：

```sh
xelatex -interaction=nonstopmode -halt-on-error -jobname=Lab1_Report_team01 report.tex
xelatex -interaction=nonstopmode -halt-on-error -jobname=Lab1_Report_team01 report.tex
```

如果选择编辑 report.md，则运行 `bash build.sh --from-md`。此命令会重新生成 report.tex，请勿用它覆盖只在 TeX 中保存的修改。

使用 XeLaTeX；需要 xeCJK 和 Noto Serif CJK SC、DejaVu Serif、DejaVu Sans Mono 字体。从 Markdown 生成 TeX 另需 Pandoc。也可将 TeX 与 figures 文件夹上传私有 Overleaf 项目，选择 XeLaTeX 编译。

## 图片

当前 PDF 包含三张由本地真实 VCD 绘制的波形，图注明确标注来源。服务器截图的结果已写入正文；聊天内嵌图片尚无可读原图文件，未写入 PDF。

将去除个人信息后的原图放入 figures，使用下列文件名，再编译即可自动加入对应段落：

- server-summary.png
- server-winograd-log.png
- server-winograd-wave.png
- server-cordic-log.png
- server-cordic-wave.png
- server-fsm-log.png
- server-bonus-log.png

图片不存在时，该插图位置自动省略，PDF 不显示待插图框。保留 FSM 图中的工具异常行，遮盖账号路径时不要删除测试证据。

## 本地填写成员信息

修改 report.tex 中的 `\author{team01}`，或在正文加入成员表格；只在本地私有副本中填写，勿推送至公开仓库。

最终检查 PDF 后，运行 `python3 package_submission.py`。输出 submission/Lab1_Report_team01.zip，内容为 PDF 和七个实现 RTL。TeX、图片、TB 和编译日志均不进入该 ZIP。
