## 设计边界及注意点

- Winograd 实现确实使用变换，1D 为 4 次乘法，2D 为 16 次乘法；不是用直接卷积冒充。为保证全范围精度采用较宽算术，未做面积/时序优化。
- 2D 打包第 0 个行优先元素位于最低 32 位，输入、权重、输出一致；报告明确此约定，课程网页未细化最低/最高端约定。
- CORDIC `done` 是流水线填满后持续为 1 的指示，不是逐任务完成脉冲；接口没有 start/reset，课程 TB 也不通过 done 比较。有效位初始化适用于 FPGA/仿真；若以后做 ASIC，必须明确上电复位方案，不能把本次仿真当成 ASIC 复位验证。
- CORDIC 任意大初始向量可能超出 16 位输出范围，按端口宽度截断；本作业规定的幅度不会溢出。无饱和逻辑。
- 已有公开 TB 保持课程包字节一致；扩展 FSM TB 另行生成在 build，仅增加测试驱动，不修改原始检查条件。
- 仿真编译有未显式 timescale 的警告；RTL 无延迟语句，不影响本次功能结果。不声称无警告、综合无误或隐藏测试必过。
