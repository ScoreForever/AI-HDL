# 服务器复验：上传什么、在哪里运行

服务器复验是在课程服务器上用 VCS 编译 RTL 和课程 Testbench，再运行仿真。不是上传课程网，也不需要 FPGA 上板。

## 所需文件

下载 `dist/Lab1_Server_Check.zip`。此包包含：

- `lab1/`：七个实现 RTL、课程原始 TB、run/Makefile 和文件列表、FSM README。
- `scripts/verify_vcs.py`：自动复验脚本。
- `docs/course_manifest.json`：官方文件哈希，用于检查 TB 和运行文件未被修改。
- `bonus/stream2.sv`、`bonus/vectors2.txt`：独立 2D 直接卷积参考测试与向量，由已运行的扩展测试生成。

不要把这个服务器复验包交到课程网。课程提交包 `Lab1_Report_team01.zip` 只有 PDF 和实现 RTL，缺少 TB 和 run 文件，不能直接用于课程复验。

## 本地电脑：连接、上传

先连接校园网络/VPN，确认自己已获课程服务器账号。以下 SERVER_HOST、SERVER_PORT、YOUR_USERNAME 分别换成课程给出的地址、SSH 端口和你的账号；不应原样输入占位符。首次连接请核对管理员提供的主机指纹。密码或私钥留在本机，不写入仓库。

在 PowerShell、Terminal 或 WSL 运行：

```sh
ssh -p SERVER_PORT YOUR_USERNAME@SERVER_HOST
```

进入服务器后，新建一个未使用过的工作目录，成功后退出。若提示目录已存在，请改名，避免覆盖：

```sh
mkdir ~/lab1-review-20261107
exit
```

在本地下载目录执行，注意 scp 的端口参数是大写 `-P`：

```sh
scp -P SERVER_PORT Lab1_Server_Check.zip YOUR_USERNAME@SERVER_HOST:~/lab1-review-20261107/
ssh -p SERVER_PORT YOUR_USERNAME@SERVER_HOST
```

## 服务器：解压、初始化、运行

```sh
cd ~/lab1-review-20261107
unzip Lab1_Server_Check.zip
command -v python3
command -v make
command -v vcs
command -v verdi
```

若没有 unzip，但有 Python3，可用 `python3 -m zipfile -e Lab1_Server_Check.zip .`。本包解压后直接出现 lab1、scripts、docs、bonus，不另套工程目录。

若找不到 VCS/Verdi，先按课程服务器说明初始化环境，再检查 PATH。只有知道真实初始化脚本位置后才执行 source；不要猜许可证变量或工具路径。`verdi` 命令存在也不证明 FSDB 插件和许可证配置正确。

在包的根目录执行：

```sh
python3 scripts/verify_vcs.py
```

脚本按顺序运行课程原始 Makefile，不需要 Icarus、Pandoc 或 LaTeX。成功时看到：

```text
winograd: 10 PASS; ALL PASS
cordic: 10 PASS; ALL PASS
fsm: 3 PASS; ALL PASS
Validated VCS logs: .../build/vcs-时间戳
```

`build/vcs-时间戳/lab1/每个任务/run/` 中保留 make.log、compile.log、simulation.log。脚本会检查返回码、PASS 数量、ALL PASS 和错误标记，不会把仅编译成功当成测试通过。

若使用原课程命令手动运行：

```sh
(cd lab1/winograd/run && make rerun)
(cd lab1/cordic/run && make rerun)
(cd lab1/fsm/run && make rerun)
```

## Bonus：2D Winograd

包内已经包含与本轮扩展测试一致的 TB 和向量，不需先在服务器安装 Icarus：

```sh
cd bonus
vcs -full64 -sverilog -top tb -o simv2 -l compile.log stream2.sv ../lab1/winograd_2d/src/winograd_2d.v
./simv2 -l simulation.log
cd ..
```

编译失败时停止，不要继续运行旧 simv2。必须在 bonus 目录执行，因为 TB 从当前目录读 vectors2.txt。预期为 `ALL PASS: 2D streaming 1200 cycles, 928 checked outputs`。

以上 VCS 命令尚未在当前云环境实测。包内同一 2D TB/向量已使用 Icarus 验证；这不等于 VCS 通过。

## Verdi 波形

先完成命令行仿真，再进入课程提供的远程图形桌面。在 Winograd/CORDIC 的 run 目录执行 `make all`，Verdi 打开后选择 Signal → Get All Signals。普通 SSH 窗口默认没有图形显示。

FSM 原 Makefile 不提供 all 目标，不要运行 `make all`。如需 FSM 波形，可在运行结束后交互式打开 Verdi 导入课程工程并按工具说明配置波形导出；已有本地实测 VCD 波形仍可用于报告。2D TB 本身产生 stream2.vcd，Verdi 可按其导入 VCD 的功能查看。

## 常见失败

- SSH 超时：检查校园网/VPN、服务器地址及端口；与 RTL 无关。
- Permission denied：检查账号与认证配置，不公开密码或私钥。
- vcs: command not found：初始化课程 EDA 环境。
- 等待许可证：检查课程许可证状态，联系管理员；不要编造许可证地址。
- 未定义 fsdbDumpfile/fsdbDumpvars：检查课程 Verdi/FSDB 插件配置；不要删改 TB。
- 没有图形 DISPLAY：用课程远程桌面；先做命令行复验。
- FAIL/ERROR/FATAL：保留 compile.log、simulation.log 和 make.log，再排查；不要改 Golden Model 或容差。
